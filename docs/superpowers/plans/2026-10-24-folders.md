# Folders Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add traditional launcher folders — a named tile on a page that opens a floating popup of its apps and shortcuts — without changing the pager, the two-level group invariant, or the saved schema.

**Architecture:** A folder is two cooperating objects in the Rust model: a root-child `Group` with `folder = true` (never a page, never in Edit Groups) and an `Item` with `folder_group_id` pointing at it (the tile, living in a real group). Membership is `Item.group_id = folder group id`, so the existing `move_item` does all moving. The snapshot gains the resolved folder icon member. Flutter adds a folder dialog, a folder popup, folder-aware cells, and a nested Group dropdown in the app popup.

**Tech Stack:** Rust 2024 (qlaunch_core, flutter_rust_bridge 2.13), Flutter/Dart (Material), existing `LauncherState`/`LauncherBackend` abstractions.

**Spec:** `docs/superpowers/specs/2026-10-24-folders-design.md`

## Global Constraints

- Schema stays at **1**; both new fields are `#[serde(default)]`.
- `Group.folder` gets `#[frb(default = "false")]` so existing Dart `Group(...)` constructors keep compiling.
- Folders are never pages: excluded from `pages()`, the pager, the tab strip, and Edit Groups.
- No folder inside a folder. No folder in the root. Folders may hold apps **and** shortcuts.
- The folder icon is the most-used member's app; ties by last-used; fallback first member in display order; empty or unusable icon -> generic folder glyph.
- Regex follow-up: do not hand-edit `lib/src/rust/**` or `rust/qlaunch_core/src/frb_generated.rs`; regenerate.
- Baseline (main) has one pre-existing failing Flutter test, `test/home_screen_test.dart` "scrolling pauses speculative loads until it ends". Do not count it as a regression, but report it.
- Do not commit unless the user approves; this plan lists commits for a normal run.

## Review Focus

1. Deleting a folder returns members to the **folder tile's current group**, not Apps and not the original group. Test in Task 2.
2. Moving a folder between groups and then deleting it returns members to the **new** group. Test in Task 2.
3. A folder with no usable icon (empty, or shortcut-only with no stored icon) renders a folder glyph, never another item's placeholder or a crash. Test in Task 6.
4. A saved document written before this feature loads and runs with `folder = false` / `folder_group_id = None`. Test in Task 2.
5. Moving a folder tile into another folder or the root is refused, while moving an app into a folder is allowed. Test in Task 2.
